bedROK

Lightweight Windows companion for Minecraft Bedrock: fullbright, overlay, crosshair, clock, module list. No combat / ESP / reach.

Download builds (Actions) Releases Source

What works

  • Fullbright — system gamma (restores when off)
  • Overlay — watermark + enabled modules
  • Crosshair · Clock · Array list

Hotkeys: F1 Fullbright · F2 Crosshair · F3 Clock · F4 Array list · F5 Watermark

How to use

  1. Open Actions → latest green run → download bedrok-windows artifact.
  2. Start Minecraft Bedrock.
  3. Run bedrok_loader.exe, select Minecraft.Windows.exe, inject bedrok.dll.
  4. Log: C:\Users\Public\bedrok.log
Limits: Fullbright is Windows gamma, not in-game night vision. Not a PvP client. Xbox/Store builds may block injection.
